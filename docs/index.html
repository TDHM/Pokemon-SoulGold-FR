Guide

Comment installer le patch ?

Le patch français doit être appliqué à une ROM de Pokémon SoulGold créée avec le patch officiel du projet original. Il ne doit pas être appliqué directement à Pokémon Émeraude. Aucune ROM n’est fournie, hébergée ou liée par ce projet.

🧩

Deux patchs successifs

Préparer SoulGold, puis appliquer la traduction

Vous aurez besoin de :

  • votre propre ROM Pokémon Émeraude US compatible, au format .gba ;
  • du patch officiel de Pokémon SoulGold, appliqué depuis Hackdex ;
  • du patch de traduction Pokémon SoulGold FR au format .bps.

1. Créer la ROM Pokémon SoulGold

  1. 1

    Ouvrez la fiche officielle de Pokémon SoulGold sur Hackdex.

  2. 2

    Repérez le numéro de version de SoulGold proposé sur la page et conservez-le pour la vérification suivante.

  3. 3

    Sélectionnez votre propre ROM Pokémon Émeraude US compatible lorsque Hackdex vous la demande, puis lancez l’application du patch officiel.

  4. 4

    Enregistrez le fichier Pokémon SoulGold .gba généré. C’est ce fichier qui servira de base à la traduction française.

Vérification obligatoire

Le numéro de version de Pokémon SoulGold doit correspondre exactement à celui indiqué pour le patch SoulGold FR. En cas de différence, n’appliquez pas le patch français : utilisez la version de SoulGold prévue pour ce patch.

2. Appliquer le patch français

  1. 1

    Ouvrez Rom Patcher JS dans un navigateur récent.

  2. 2

    Dans ROM file, sélectionnez le fichier Pokémon SoulGold .gba obtenu avec Hackdex — et non votre ROM Pokémon Émeraude.

  3. 3

    Dans Patch file, sélectionnez le patch Pokémon SoulGold FR .bps correspondant à cette version de SoulGold.

  4. 4

    Vérifiez les informations affichées, puis choisissez Apply patch.

  5. 5

    Enregistrez le nouveau fichier .gba généré, puis importez-le dans un émulateur compatible ci-dessous.

Les patchs sont appliqués à vos propres fichiers. Ni Hackdex ni ce site ne vous dispensent de posséder une copie compatible de Pokémon Émeraude ; aucune ROM n’est fournie ici.

Compatibilité

Choisir un émulateur

Pokémon SoulGold dépend de comportements GBA que certains anciens émulateurs ne reproduisent pas correctement. Privilégiez les options testées ci-dessous.

🍎

Mobile Apple

iPhone / iPad

Utilisez RetroArch avec le cœur mGBA, ou Manic EMU avec son cœur mGBA. Importez le fichier .gba patché, sélectionnez le cœur mGBA lorsque l’application le demande, puis lancez le jeu depuis votre bibliothèque.

À éviter : Delta n’est pas recommandé pour SoulGold en raison de différences d’émulation.

🤖

Mobile Android

Android

Les options prises en charge sont RetroArch avec le cœur mGBA, Lemuroid et Pizza Boy A Basic. Ajoutez le fichier .gba patché à la bibliothèque de l’émulateur, puis lancez-le normalement.

Non pris en charge : My Boy! n’est actuellement pas compatible avec SoulGold.

💻

Ordinateur

PC / Mac / Linux

mGBA est le choix recommandé sur Windows, macOS et Linux. Vous pouvez aussi utiliser RetroArch avec le cœur mGBA. Ouvrez simplement le fichier .gba patché depuis l’émulateur.

Non pris en charge : VisualBoyAdvance / VBA n’est actuellement pas compatible avec SoulGold.
