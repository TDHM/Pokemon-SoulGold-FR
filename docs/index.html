Guide

Comment installer le patch ?

Le patch SoulGold FR s’applique directement à votre propre ROM compatible de Pokémon Émeraude US. Aucune ROM n’est fournie, hébergée ou liée par ce projet.

🧩

Un seul patch BPS

Appliquer le patch SoulGold FR avec Rom Patcher JS

Vous aurez besoin de :

  • votre propre ROM Pokémon Émeraude US compatible et non modifiée, au format .gba ;
  • du patch de traduction Pokémon SoulGold FR v1.1.1 au format .bps, téléchargeable en haut de cette page.
  1. 1

    Ouvrez Rom Patcher JS dans un navigateur récent.

  2. 2

    Dans ROM file, sélectionnez votre propre ROM Pokémon Émeraude US compatible au format .gba.

  3. 3

    Dans Patch file, sélectionnez le patch Pokémon SoulGold FR v1.1.1 .bps.

  4. 4

    Vérifiez que l’outil n’affiche pas d’erreur de compatibilité, puis choisissez Apply patch.

  5. 5

    Enregistrez le nouveau fichier .gba généré, puis importez-le dans un émulateur compatible ci-dessous.

Le patch est appliqué localement dans votre navigateur. Ce site fournit uniquement le fichier de patch BPS : vous devez posséder votre propre copie compatible de Pokémon Émeraude.

Compatibilité

Choisir un émulateur

Pokémon SoulGold dépend de comportements GBA que certains anciens émulateurs ne reproduisent pas correctement. Privilégiez les options testées ci-dessous.

🍎

Mobile Apple

iPhone / iPad

Utilisez RetroArch avec le cœur mGBA, ou Manic EMU avec son cœur mGBA. Importez le fichier .gba patché, sélectionnez le cœur mGBA lorsque l’application le demande, puis lancez le jeu depuis votre bibliothèque.

À éviter : Delta n’est pas recommandé pour SoulGold en raison de différences d’émulation.

🤖

Mobile Android

Android

Les options prises en charge sont RetroArch avec le cœur mGBA, Lemuroid et Pizza Boy A Basic. Ajoutez le fichier .gba patché à la bibliothèque de l’émulateur, puis lancez-le normalement.

Non pris en charge : My Boy! n’est actuellement pas compatible avec SoulGold.

💻

Ordinateur

PC / Mac / Linux

mGBA est le choix recommandé sur Windows, macOS et Linux. Vous pouvez aussi utiliser RetroArch avec le cœur mGBA. Ouvrez simplement le fichier .gba patché depuis l’émulateur.

Non pris en charge : VisualBoyAdvance / VBA n’est actuellement pas compatible avec SoulGold.

Questions fréquentes

FAQ

Est-ce une ROM complète ?

Non. Seul un patch de traduction sera distribué. Aucune ROM n’est fournie.

La traduction est-elle terminée ?

Oui. La traduction est terminée et la version publique 1.1.1 est disponible.

Les sauvegardes de la version anglaise sont-elles compatibles ?

Oui. Les fichiers de sauvegarde de la version originale en anglais sont compatibles avec la traduction française.

Où télécharger le patch français ?

Utilisez le bouton « Télécharger le patch SoulGold FR » en haut de cette page. Le téléchargement contient uniquement le patch BPS de traduction, jamais une ROM.

Quelle ROM de base faut-il utiliser ?

Le patch SoulGold FR doit être appliqué directement à une ROM Pokémon Émeraude US compatible et non modifiée. Il ne nécessite pas de ROM SoulGold déjà patchée.

Puis-je partager le patch ?

Pour partager le projet, renvoyez vers mes comptes Instagram ou TikTok @tdhm2026. Ne partagez jamais de ROM.
